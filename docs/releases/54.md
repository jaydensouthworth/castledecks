# Release 54

This release brings a player-facing homepage and a shared card workspace to the accepted release-51 game. Development details now live on `/about`; `/battle` opens the game.

## Changes

- Discover, compare, acquire and equip ability cards in one full-viewport Deck/Build workspace.
- Read illustrated equipped cards and move or swap them through card lifting, tap placement or keyboard placement. Cancelling a drag with Escape retains the workspace.
- Prepare from a live table showing the current company, cards and next field. Campaign, Wayfarer, Training and Skirmish keep separate sessions and open in preparation.
- Grow the allied field cap through campaign milestones and use quick Advance/Rally commands to release or hold a fixed line.
- Use readable phone tabs and complete horizontal card rows on short landscape screens.
- Open the new homepage for play modes, preparation guidance and browser-save information; use About for implementation details and development tools.

The game remains static and browser-local. The Docker image uses Nginx on port 80 and retains extensionless routes, JavaScript module MIME handling, cache revalidation and missing-file 404s. No game backend was added.
