# Release 51

This snapshot includes the accepted release-45 foundation and the next round of playability, practice and quality improvements.

## Added since release 45

- Remappable keyboard controls with browser-local preferences and labels that follow the actual bindings
- Optional guided Training with mode-aware input, objectives and camera framing
- Named deck capture, comparison, application and portable codes, with ownership checks and safe older-checkpoint handling
- Versioned seeded Skirmish fields, finite enemy companies and supplied practice kits, isolated from earned campaign progress
- Result-screen deck inspection/export, fresh-kit restart and clearer saved-deck navigation
- A map-dominant narrow campaign layout and more usable compact Army rows
- Clearer original flying-unit artwork and opt-in, in-memory battle diagnostics

## Quality improvements

- Brief activation and Enter/Leave key taps survive between simulation ticks.
- Single-card and cart purchases consistently accept an exact gold balance.
- Guided drills credit actual damage caused by eligible shots.
- Diagnostics receive explicit preparation, running, paused and result context instead of guessing phase from an engine flag.
- Diagnostics are disabled initially, bounded in memory and explicitly exported. They do not send telemetry, retain profile identity or include a save/replay payload.

## Automated verification

The complete release-50 portable gate passed 1,349 checks with no skipped checks: 1,345 game regressions and four local-server checks. Release 51 adds seven focused diagnostics-phase cases, for 1,356 checks in the final repository suite. The final local validation uses those focused additions; GitHub Actions runs the complete source validator and bounded-concurrency suite on the exact committed tree from the dependency lockfile.

The pinned historical-reader fixtures contain independent implementation source previously published in this repository. Their byte hashes are checked before import; they require no original-game archives, old private Git history, machine-specific paths or directory-symlink privileges.

## Acceptance and remaining limits

Browser acceptance covered earned campaign progression/reload, paid Army/Armory flows, narrow maps and galleries, remapped controls, named deck workflows, the seeded workshop, natural practice victory and fresh-kit restoration. Release-51 browser readback confirmed that the pre-Start report shows preparation and unsettled state at tick zero. The final quality pass also covered exact-budget single/cart purchases, brief activation and Enter/Leave keys, report recording/copy/clear, actual Training high-arc and Ice credit, Skirmish hall geometry, and opening-charge reload without duplicate spending.

Physical Android touch/orientation/lifecycle, extended-session stability and a native portable save-file round trip still need acceptance. Checkpoints resume safe battle openings or settled results, not a live battlefield. Export a backup before clearing browser data. Original Flash runtime equivalence is not claimed.
