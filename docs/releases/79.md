## Complete company orders

The existing 44-pixel live picker offers twelve complete commands: All ground, Frontline and Support, each with Advance, Rear hold, Center hold and Forward hold. Each option names its company and action. Choosing one issues that named order immediately; there is no persistent target mode. All ground replaces both company orders, while a named company command preserves the other group's order. The separate remappable all-ground shortcut retains its existing release/rally behavior.

The compact two-line readout derives from the current order snapshot on every render. Unified orders show All ground; split orders may show the last-commanded company's current state. The existing all-ground button continues to identify split orders. A brief visible receipt reports that an order was issued and, for a named company, reports the other company's retained order. Neither readout claims that troops have already arrived.

External Army commands, the all-ground shortcut, automatic keep/Causeway release and battle replacement refresh the state. Company receipts have bounded lifetime and explicit ownership: later order/outcome events clear only the matching receipt, preserving an unrelated replacement warning. No extra permanent live HUD row is added.

## Native picker semantics and guards

A native SELECT change is the commit edge. On platforms that commit collapsed-select arrow changes immediately, each intermediate command applies only to the company explicitly named by that option. Enter adds no synthetic second dispatch. Focus stays in the picker until the player leaves; R and movement keys remain native text-control input while it has focus. Tab out to use gameplay shortcuts, or use the independent all-ground touch button.

Escape performs native dismissal, does not bubble into global Pause, and does not undo an order already issued. Cancellation with no change event issues nothing. Unchanged render frames preserve native option navigation. Stale battle interactions and unavailable, paused, hidden, pre-start, guided or settled states cannot issue new live orders.
