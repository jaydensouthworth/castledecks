## New-target eligibility

The only functional runtime change is in `site/dist/engine/ranged-troop.mjs`. A local archer eligibility guard rejects already-dead or destroyed enemies during new flag-carrier priority and nearest-enemy fallback acquisition. Regular friendly and enemy archers both receive unfiltered enemy lists, so both paths need this guard.

Living-target ordering, equal-distance ties, the existing first-two-eligible-carrier rule, visibility/garrison rules and structure distance preference remain intact. All 39 other engine modules, committed load/aim/release behavior, launched projectiles, costs, cooldowns and the shared liveness helper are unchanged. A target acquired while living may still die before its already-committed shot; this release deliberately preserves that behavior.
