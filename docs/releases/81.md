## Interaction visibility

The optional viewport lab distinguishes painted surfaces from eligible interaction targets. Inert content and controls concealed inside closed disclosures no longer contribute target-size or control-overlap warnings. The first direct summary of each disclosure remains eligible, including while its disclosure is closed. Nested disclosures must expose the target through every enclosing disclosure. Extra or detached summaries are not treated as exposed disclosure controls.

Painted inert HUD surfaces remain in the diagnostic's occlusion totals. Existing size thresholds, label normalization and deduplication, viewport clipping, overlap tolerance, 35 aim samples, coverage and area budgets are unchanged. Disabled controls retain their existing treatment. This correction does not remove genuine small-target, overlap, HUD coverage or aim-interception warnings.

Only diagnostic interaction visibility and build metadata change at runtime. All 40 engine modules, game CSS, player controls, comparison behavior, combat rules, saves and feature-off account state remain unchanged. No new gameplay feature, backend or provider activation is included.
