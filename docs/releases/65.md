# Release 65 candidate

This narrow preparation and feedback correction was initially published with native acceptance pending. The exact release 65 subsequently passed its native checks and is the known-good rollback for release 66.

## Changes

- Let authored trial actors wait until the first actual selected-contract unit spawns. Reading before deployment no longer lets the trial's enemies rush the flag. The trial explicitly describes this preparation assistance.
- Keep the existing recruitment queue and its timer phase, costs, reserve, cooldown, Basic Arrow and effects active. The original actor step functions resume permanently on the first spawn; recruit death cannot rearm preparation. Reset creates a fresh fixture.
- Allow actual Basic Arrow damage to a waiting target without crediting it as recruit damage or inventing a replacement target.
- Make portrait and Pause labels describe the stopped reinforcement stream instead of the suspended director's old reserve count. Name the selected contract in the Pause title; ordinary campaign/Skirmish wording remains unchanged.

Every engine file is byte-for-byte unchanged. The disposable practice fixtures, ordinary combat values and origin-state restoration are retained. Preparation assistance is explicit and is not evidence of ordinary combat balance.
