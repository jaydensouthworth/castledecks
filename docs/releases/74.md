# Release 74 candidate

This candidate improves the short-landscape Build collection. Native acceptance is pending. [Accepted release 73](https://github.com/jaydensouthworth/castledecks/commit/c6579d80903ce73370ebfb3af2d3ac5297a2551a) remains the rollback. Source revision: `097211d22fe98f04b3db084aad265086bc29f76a`.

## Changes

The accepted-73 layout at 740x320 with simulated 44-pixel side and 24-pixel bottom insets left a 61-pixel nested card viewport inside a 177-pixel inventory pane. A complete Basic card was 113 pixels tall, requiring scrolling inside a fraction of one card.

Short-landscape inventory now owns one collection scroll surface. Search, full card-page rows and pagination stay in ordinary document flow so each card's identity, facts and controls remain together. The new scroll owner participates in existing drag edge scrolling. Search and page transitions reset the correct pane while inspection and castle rerender preserve its identity and offset.

At widths of at least 640 CSS pixels in short landscape, read-only resource facts use spare header-center space and reclaim the former resource row's vertical budget. Navigation, search, refine, pagination and drag controls remain present. This adds no alternate gameplay mode. Portrait and desktop rules retain their established layout; all 40 engine modules, abilities, prices, ownership, saves and artwork remain unchanged.

## Verification and limits

The exact canonical aggregate gate passed 2,234 engine, UI and recruitment checks with zero failures, cancellations or skips. The portable mirror adds eight existing server/packaging checks for an expected 2,242 and preserves all 188 runtime files byte-for-byte. Seven new checks cover bounded CSS scope, complete-card flow, read-only resources, drag scroll ownership, search/page resets, reachability of all 25 supplied owned abilities and inspector/castle scroll preservation. These source/behavior tests do not establish browser-computed pixel geometry.

CI repeats the portable aggregate gate, builds the production Docker/Nginx image, checks routes, MIME/cache/404 behavior and compares every served runtime file byte-for-byte.

Native acceptance must measure complete card-name, identity, deployment and Inspect visibility at 740x320 and 915x360; search/refine/page access; mouse drag and keyboard assignment; unchanged ownership/gold; expanded castle scrolling; mobile portrait; resource/Back clearance; and session return. Candidate publication is not native acceptance.

Causeway, Highwatch and same-card castle keyboard behavior remain from accepted 73. This collection-layout change does not claim to resolve separate dense live-HUD aim-interception warnings. Physical Android/touch/lifecycle, GPU-presented FPS, end-to-end latency, extended-session stability and broad non-Auto human difficulty remain unverified. Accounts and provider/backend operation remain disabled and unverified. Full raw live-host byte equality remains unverified and separate from CI-container proof.
