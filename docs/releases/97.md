# Release 97 candidate

Release 97 improves the continuity of Hall, Build and shopping while retaining the existing Catalog/Collection and Build placement layout. It builds on accepted release 96's nested comparison-scroll repair.

## Hall, Build and shopping

- Hall save status is a secondary, initially closed disclosure. Its summary reports saving or failure attention, remains keyboard-focusable, and keeps the existing save/status choices and Start's required existing-save decision.
- Build keeps placement, cards, name/effect/role search, detailed refinements and twelve-card pages. New type and current-bar/equipped/reserve filters help find cards. The resource row and secondary navigation match the shop; real Wishlist/Cart/Compare counts cannot expose a previous profile's temporary cart.
- Wishlist reuses actual Catalog card artwork and markup. Its empty state explains saving cards and links to browsing. Catalog/Collection-specific composition remains intact.
- Cart rows use shared card artwork, tone, name and price with the existing atomic checkout and return guards.
- Discover adds all-card search and one real collection spotlight selected from ownership, falling back to stable editorial order. Existing collection contents and missing-card prices remain authoritative. No popularity, scarcity or discount claims are introduced.
