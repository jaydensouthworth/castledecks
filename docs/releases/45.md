# Release 45

This source snapshot brings the campaign and preparation screens together as a more complete Castledecks prototype.

## Included

- Illustrated command hall and a regional campaign atlas
- A separate Wayfarer Charter expedition mode
- Device-local safe campaign checkpoints, conflict protection and portable exports
- Illustrated ability cards, armory discovery and cart controls
- A searchable loadout collection and an Army command ledger
- Enemy intelligence, dragon counters and clearer garrison feedback
- Keyboard focus recovery after paid Army queue actions
- Compact map labels and readable Army reserve/queue labels

The browser runtime remains a static JavaScript/Canvas game. Test-only native canvas tooling is pinned separately and is not shipped to the browser.

## Verification

The frozen snapshot passes 1,034 checks: 1,030 game regressions and four local-server checks. The same validation and test gate runs in GitHub Actions from a clean dependency install.

Browser acceptance covered paid Queue keyboard recovery and focus wrapping, visible 12-pixel ledger text, portrait labels and compact atlas labels. Earlier browser checks also covered the main map, Armory density and paid Army flows.

## Known limits

- At a 740-pixel-wide Army layout, one roster row can remain partly clipped. A presentation follow-up is needed.
- Real-device Android touch/orientation behavior and extended-session stability still need acceptance.
- Checkpoints restore safe campaign openings or settled results, not a live battlefield. Keep an exported backup before clearing browser storage.
- Node integration checks do not establish complete browser/device behavior or exact compatibility with the original Flash game.
