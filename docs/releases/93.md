# Release 93 candidate

This candidate adds visible banner identity and customization to the Hall while preserving accepted release 92's Wayfarer directory-return correction. A named banner card opens a dedicated editor for the existing profile name and three heraldry palettes. Live standard and selected-keep previews are draft-only. Apply commits through the existing safe settings-checkpoint path; Cancel, Back and Escape discard the draft. Navigation, profile replacement and session changes invalidate stale handlers. No gameplay statistics, resources, equipment ownership, palette IDs or authored stages are added.

## Banner identity and bounded presentation

New names are limited to 1–32 characters at the UI boundary. An untouched imported name can retain its existing longer value. Full identity remains visible in the banner card and mission text; the compact Hall heading identifies the destination. Local-save and history summary names wrap within their grids. The editor's sticky action bar has a zero bottom inset and retains 48-pixel action targets inside its scrollport. Allied heraldry remains distinct from enemy, element and status cues.

The owner integrated bounded lifecycle changes with the release 92 return wiring rather than replacing battle coordination wholesale. Four runtime files are added: the customization model, editor, stylesheet and banner renderer. Battle coordination, battle markup, phone-preview version labels and progress metadata change. The other 197 runtime files, including all 40 engine modules and existing profile, local-save, deck and cloud codec/transport modules, remain byte-identical to accepted release 92.

The new regression asset adds 34 checks for draft/apply/cancel behavior, stale and interrupted flows, profile and session invalidation, safe persistence fixtures, imported-name compatibility, rendered cue separation, focus, the sticky action-bar boundary and 32-character identity presentation. Existing tests and compatibility readers are retained.
