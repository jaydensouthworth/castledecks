# Release 76 candidate

This narrowly corrects the portrait row budget in [candidate 75](75.md), which was not accepted. Native acceptance of 76 is pending. [Accepted release 74](https://github.com/jaydensouthworth/castledecks/commit/877c974d6cc98d241b01187156dc21d3b4500f04) remains the rollback. Source revision: `5b0f0bafb5b7697db4452a9c256e66bfe445519b`.

## Native defect and correction

Native 75 at 360x640 with a 24-pixel bottom inset had a 375-pixel Build workspace, but its positive-minimum grid tracks demanded 170 + 235 = 405 pixels. Inventory extended below the footer. At the bottom of its collection, Next occupied vertical 538.125-582.125 while the footer began at 560, clipping 22.125 pixels of the target. Complete illustrated rows and successful drag/keyboard actions did not make that paging defect acceptable.

The only functional runtime change in 76 is the final scoped portrait grid rule: `minmax(0,.65fr) minmax(0,1fr)`. Placement and collection now share the actual flex allocation with zero minimum tracks. The independent scroll panes, compact illustrated rows and ordinary-flow pagination remain. All 40 engine modules, card artwork, callbacks, economy and save semantics are unchanged. No AI correction or new Muster variant is included.

## Verification and limits

The exact canonical aggregate gate passed 2,242 engine, UI and recruitment checks with zero failures, cancellations or skips. The portable mirror adds eight existing server/packaging checks for an expected 2,250 and preserves all 188 runtime files byte-for-byte.

The affected source-cascade assertions explicitly check the final fractional rule. One added regression guards its precedence and zero minima. Fractional arithmetic and source checks do not prove native browser rendering or complete target visibility. CI repeats the portable aggregate gate, builds the real production Docker/Nginx image, validates HTTP behavior and compares every served runtime file byte-for-byte.

Native acceptance must prove the full 44 pixels of Previous and Next are visible and clickable at the scroller's end, together with complete first-card facts/Inspect, both portrait sizes, rotation, expanded castle details and short-landscape long-return-label clearance. Candidate publication alone is not acceptance.

Physical Android/touch/lifecycle, GPU-presented FPS, end-to-end latency, extended-session stability and broad human non-Auto difficulty remain unverified. Separate dense live-HUD warnings are outside this correction. Accounts and provider/backend operation remain disabled and unverified. Full raw live-host byte equality remains unverified and is separate from CI-container proof.
