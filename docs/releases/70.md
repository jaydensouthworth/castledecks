The only functional runtime changes from release 69 are in game-shell.css and loadout-collection.mjs, with build/cache/progress metadata aligned to 70. All 37 engine modules and all artwork are unchanged. Account defaults remain disabled and unconfigured; no Go backend, provider configuration or unrelated prototypes are included.
