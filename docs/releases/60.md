# Release 60 candidate

This is a source-tested candidate for native browser acceptance. Its new optional Battery interception mode has not yet completed that acceptance gate. [Release 59](https://github.com/jaydensouthworth/castledecks/commit/72249c430366ec215d2bb97c7f3ccb8dcfef40b9) is the known-good rollback.

## Changes

- Choose Battery interception as an optional supplied Skirmish doctrine. The default and three existing doctrines are unchanged.
- Silence two marked ordinary enemy trebuchets protected by a finite escort. These units come from the scenario roster and use ordinary combat values and AI.
- Resolve the two original marked identities and keep the home flag at base. Destroying the enemy keep or capturing its flag does not replace the objective. If the battery is resolved while the home flag is away, recover it to finish.
- Distinguish destroyed and secured originals. Unrelated or newly spawned siege units cannot count toward the two targets.
- Give hero death and home-flag loss precedence over objective completion in the same completed simulation tick.
- Show preparation counterplay, real-actor Canvas markers, target counts, home-flag recovery guidance and Pause details through the existing interface. Retry starts a fresh supplied attempt.

The objective is isolated from earned campaign progress, existing save formats, regular Skirmish defaults and the Wayfarer charter. No backend, network service or broader army redesign was added.

## Verification and status

The exact candidate source passed 1,528 combined engine, UI and recruitment checks with zero failures or skips. The public mirror preserves all 158 runtime files byte-for-byte and adds eight portable server/packaging checks for 1,536 checks in its complete gate.

Coverage includes strict optional descriptors, real finite-roster targets, tick-zero preparation, immutable snapshots, original target identity, live allegiance, home-flag recovery, simultaneous defeat precedence, pause/retry, bounded marker geometry and read-only presentation. A committed generated JSON fixture checks 144 legacy Skirmish scenario/combat streams against the implementation's previous output. These are implementation tests; no original Flash material is included.

The release gate validates syntax, markup, asset references and publication hygiene, then runs all portable tests. GitHub CI installs pinned test dependencies and builds the actual Docker/Nginx image, checking configuration syntax, real HTTP routes, exact served source bytes, module MIME, cache headers and missing-file responses.

Native acceptance of Battery interception is pending on the deployment built from this source. Automated DOM/Canvas and marker tests do not establish native layout, aiming, focus, a natural browser victory or physical touch performance. The preceding release's accepted route/Rally/navigation checks do not imply acceptance of this new mode.

Physical Android/touch, orientation and lifecycle behavior, extended browser stability, native portable save-file round trips, broad balance and exact original Flash runtime equivalence remain unverified. Existing HUD coverage limits and browser-local save restrictions still apply. Export saves before changing website address or clearing browser data.
