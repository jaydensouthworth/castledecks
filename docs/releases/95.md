# Release 95 candidate

Release 94's initial native card-led presentation, eight-size readability, temporary purchase and paused-battle guard checks passed, but its outgoing Discover vertical scroll returned to zero through inspection, cart, wishlist and comparison. Further native inspection found three illustrated collection-detail cards forcing Wishlist and Compare into unreadable narrow columns at 412-pixel portrait width even without overflow. Release 94 was not forwarded to the custom site. Accepted release 93 remains the bounded custom-site baseline.

## Narrow outgoing-stage repair

The root cause was lifecycle order: showStage applied display:none before reading the departing stage's scrollTop. Native browsers report zero scroll metrics for the hidden layout. The general UI harness retained its assigned numeric value and therefore masked this defect.

Release 95 captures outgoing stage scroll and clears departing stage content before applying visibility changes. The only other functional change is a bounded CSS rule at portrait widths up to 620 pixels: illustrated collection-detail cards use one full-width column, giving their existing actions more room. Card-led Discover presentation, catalog prices, engine rules, save/cloud/deck protocols and banner customization are unchanged. One Armory module, one CSS file and four build-metadata files change; no runtime path is added. The remaining 199 of 205 runtime files, including all 40 engine modules, are byte-identical to release 94.

Two new regression checks explicitly emulate scrollTop becoming zero when a stage is hidden. They cover Discover inspection Back and Escape, cart, wishlist, comparison, collection inspection and nested comparison/cart returns. Both fail against release 94 and pass after the correction. A third new regression checks the bounded portrait collection rule. Together with the existing Shopfront tests, the focused gate passes 14 checks. The existing horizontal shelf and focus assertions remain. No price, ownership or acquisition rule changes.
